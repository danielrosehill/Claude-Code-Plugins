Check whether the generated catalogue is up to date with `.claude-plugin/marketplace.json`. **Read-only — do not edit or regenerate.**

`README.md` and `docs/categories/` are generated by `scripts/generate-catalogue.py`.
Drift means the generator's output would differ from what is committed.

Your task:

1. Validate the manifest: `claude plugin validate .claude-plugin/marketplace.json`
2. Check every entry has `displayName` and `category`:

   ```bash
   python3 -c "import json;d=json.load(open('.claude-plugin/marketplace.json'));print([p['name'] for p in d['plugins'] if not p.get('category') or not p.get('displayName')])"
   ```

3. Detect drift without writing to the working tree:

   ```bash
   python3 scripts/generate-catalogue.py && git diff --stat -- README.md docs/categories/
   ```

   A non-empty diff is drift. Report it, then restore with
   `git checkout -- README.md docs/categories/` so the tree is left clean.

4. Also report, as manifest-level findings the generator cannot catch:
   - Duplicate `name` values.
   - Entries whose `description` is uninformative in its **first 59 characters** —
     that is all Claude Code's `/plugin` browser shows in the list, and it is the
     only free-text field the browser's search matches. See the note in `CLAUDE.md`.
   - Categories holding a single plugin, which usually means a typo.

5. Check no plugin source has been committed into this manifest-only repo:

   ```bash
   git ls-files -s | awk '$1=="160000"'
   ```

   Any output is a **gitlink** — a submodule entry, usually with no `.gitmodules`,
   left behind by cloning a plugin repo inside this one. Fresh clones cannot
   resolve it. Remove with `git rm --cached <path>`. This has recurred three times
   (`repo-retrofitter-plugin` twice, `Claude-Handover`); `plugins/` is now
   gitignored, but `git add -f` and `git submodule add` still bypass that.

6. End with: `<n> plugins / <n> categories / drift: yes|no / gitlinks: <n>`

7. Do not offer to auto-fix unless asked. If asked, point at `/sync-readme`.
